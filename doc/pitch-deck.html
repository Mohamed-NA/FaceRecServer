How It Works

From camera frame to
named identity in milliseconds.

① Detect

HOG face detector finds bounding boxes in each frame. Runs on CPU — no GPU needed.

② Embed

dlib ResNet maps each face to a 128-dimension vector. Same model behind 99.38% LFW accuracy.

③ Match

Cosine distance against stored embeddings. Green box = known. Red box = unknown. Threshold tunable.
